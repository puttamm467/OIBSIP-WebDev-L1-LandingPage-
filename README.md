# OIBSIP-WebDev-L1-LandingPage-
🌐 BrightLearn – Online Learning Landing Page

📌 Project Overview

BrightLearn is a responsive landing page designed for a fictional online learning platform. The website is developed using HTML5 and CSS3 with a clean, modern, and user-friendly design.

The main objective of this project is to demonstrate fundamental web development skills, including webpage structure, styling, navigation, and responsive layouts.

🎯 Project Objective

To create a visually attractive and responsive landing page for an online learning platform using HTML5 and CSS3.

🛠️ Technologies Used

- HTML5 – For creating the structure of the webpage.
- CSS3 – For styling, layouts, colors, and responsive design.

✨ Features

- Responsive navigation bar with Home, Features, About, and Contact links.
- Attractive hero section with a headline and call-to-action button.
- Features section with three feature cards.
- About section describing the BrightLearn platform.
- Contact section with a contact button.
- Footer with social media links.
- Consistent color scheme and typography.
- Hover effects for interactive elements.
- Mobile-friendly responsive layout.
- Smooth scrolling between sections.

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the "index.html" file.
4. Right-click and select Open with Live Server.
5. The BrightLearn landing page will open in your web browser.
